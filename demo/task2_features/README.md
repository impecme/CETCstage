# Task 2 Features Demo

## Build

```bash
./scripts/build/build_v1.sh
```

## Run

```bash
./build/demo/task2_features/task2_features_demo
python3 demo/task2_features/visualize_task2.py
```

## Outputs

- `data/generated/demo/task2_features/input/`
- `data/generated/demo/task2_features/output_samples/`
- `data/reports/demo/task2_features/latest_summary.md`
- `data/reports/demo/task2_features/latest_metrics.json`
- `data/reports/demo/task2_features/latest_stage_timings.csv`
- `data/reports/demo/task2_features/figures/`
- `data/reports/demo/task2_multidomain_l1_l6_scale_performance.*`

`latest_summary.md` and `latest_metrics.json` include `mixed_error` for each CPU/GPU comparison. The metric uses absolute error near zero-valued CPU references and relative error elsewhere, matching the unit benchmark reporting policy.

The visualization script overwrites the figure PNGs with Word-friendly styling:
300 dpi output, A4正文宽度画布, and larger titles, axis labels, ticks, legends, and
colorbar labels. The L1-L6 scale performance figure is regenerated by
`scripts/test/run_task_demos.sh --scale-sweep`.

## Fixed Scenario

Equivalent to scale `L3`.

- `fs = 1e6`
- `num_frames = 48`
- `samples_per_frame = 1024`
- `template_length = 256`
- `target_start_sample_0 = 220`
- `target_step_per_frame = 3`
- `interferer_start_sample = 640`
- `target_amplitude = 1.0`
- `interferer_amplitude = 0.45`
- `snr_db = 12`
- `seed = 20260414`

## Scale Levels

The demo accepts `--scale-level 1..6`. If omitted, it uses `L3` to keep the
historical visualization scenario stable. `scale_value` is
`num_frames * samples_per_frame`, and `rx_shape` is
`num_frames x samples_per_frame`.
