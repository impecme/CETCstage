# Task1 Radar Demo

## Build

```bash
./scripts/build/build_v1.sh
```

## Run

```bash
./build/demo/task1_radar/task1_radar_demo
python3 demo/task1_radar/visualize_task1.py
```

## Outputs

- `data/generated/demo/task1_radar/input/`
- `data/generated/demo/task1_radar/output_samples/`
- `data/reports/demo/task1_radar/latest_summary.md`
- `data/reports/demo/task1_radar/latest_metrics.json`
- `data/reports/demo/task1_radar/latest_stage_timings.csv`
- `data/reports/demo/task1_radar/figures/`
- `data/reports/demo/task1_radar/task1_l1_l6_scale_performance.*`

`latest_summary.md` and `latest_metrics.json` include `mixed_error` for each CPU/GPU comparison. The metric uses absolute error near zero-valued CPU references and relative error elsewhere, matching the unit benchmark reporting policy.

The visualization script overwrites the figure PNGs with Word-friendly styling:
300 dpi output, A4正文宽度画布, and larger titles, axis labels, ticks, legends, and
colorbar labels. The L1-L6 scale performance figure is regenerated by
`scripts/test/run_task_demos.sh --scale-sweep`.

## Fixed Scenario

- single-target baseline, equivalent to scale `L3`
- `fs=1e6`
- `num_pulses=64`
- `samples_per_pulse=256`
- `template_length=64`
- `prf=2000`
- `delay_samples=48`
- `doppler_hz=125`
- `snr_db=20`
- random seed `20260414`

## Scale Levels

The demo accepts `--scale-level 1..6`. If omitted, it uses `L3` to keep the
historical visualization scenario stable. `scale_value` is
`num_pulses * samples_per_pulse`, and `rx_shape` is
`num_pulses x samples_per_pulse`.

| level | num_pulses | samples_per_pulse | rx_shape | template_length | delay_samples | pulse_compression_nfft | pulse_doppler_nfft | scale_value |
|---:|---:|---:|---|---:|---:|---:|---:|---:|
| L1 | 32 | 128 | 32 x 128 | 32 | 24 | 128 | 32 | 4096 |
| L2 | 48 | 256 | 48 x 256 | 64 | 48 | 256 | 64 | 12288 |
| L3 | 64 | 256 | 64 x 256 | 64 | 48 | 256 | 64 | 16384 |
| L4 | 96 | 512 | 96 x 512 | 128 | 96 | 512 | 128 | 49152 |
| L5 | 128 | 1024 | 128 x 1024 | 256 | 192 | 1024 | 128 | 131072 |
| L6 | 192 | 1536 | 192 x 1536 | 384 | 288 | 2048 | 256 | 294912 |

## Python Dependency

The visualization script requires `python3`, `numpy`, and `matplotlib`.
