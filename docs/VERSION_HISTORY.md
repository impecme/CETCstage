# 版本台账

本台账保留影响最终代码、接口和验证口径的里程碑。逐候选命令、协作流水和计划
文档不属于最终交付。

| 版本 | 主要结果 | 兼容性或验证变化 | 状态 |
| --- | --- | --- | --- |
| V1 | 建立 53 个信号处理算子骨架、CPU/GPU 对照和基础测试 | 初始公开接口与模块目录 | 已关闭 |
| V2.1 | 冻结 C++17 公开 API | 统一 namespace、参数和结果结构 | 已关闭 |
| V2.2-V2.3 | 建立误差、计时和统一测试报告 | 区分 accuracy 与 perf 语义 | 已关闭 |
| V2.4 | 引入 Host/Device 双输入和 Device 输出 | 仅显式 `get()` 执行 D2H，属于接口演进 | 已关闭 |
| V2.5-V2.7 | 补齐存储、平台和测试公共层 | 强化资源所有权与边界校验 | 已关闭 |
| V2.8 | 冻结 reference/generated manifest 数据模式 | 输入、期望输出、规模和容差可机读 | 已关闭 |
| V2.9-V2.13 | 逐模块补齐 waveforms、filtering、spectral、radartools 等能力 | 最终形成 12 模块 | 已关闭 |
| V3 | 完成 Task1 雷达流程和 Task2 多域特征流程 | 任务步骤和逐步报告成为正式契约 | 已关闭 |
| V4.1-V4.5 | 迁移至中科芯 ZQ500，建立 SDK/API 兼容门 | NVIDIA 路径退出最终产品主线 | 已关闭 |
| V4.6 | 平台类型和后端命名收敛 | `cuda_backend/Cuda*` 改为 `zx_gpu_backend/ZxGpu*`，为破坏性变更 | 已关闭 |
| V4.7 | 补齐迁移算子、平台探针和任务链路 | ZQ500 成为唯一构建平台 | 已关闭 |
| V4.8 | 报告字段平台中性化 | `cuda_*` 报告键改为 `gpu_*`，为数据模式变更 | 已关闭 |
| V5.0-V5.4 | 建立 task27/core53/extended28/all81 集合、接口和类型门禁 | 原 28 个候选算子全部进入正式测试注册表 | 已关闭 |
| V5.5 | 完成 81 算子、14 任务步骤和 dtype 契约收束 | all81 `81/81`，dtype 缺口 `0` | 已关闭 |
| V6.0-V6.7 | 进行任务和热点性能优化，保留正式通过的 21 个方向 | 每个候选须有基线、门禁和回退结论 | 已关闭 |
| V6.8 | V6-0138 硬门、V6-0141 all81 L1-L6 终测 | 24/24、168/168、486/486；报告语义边界见验证文档 | 已关闭 |
| V7.0-V7.5 | 深度优化及最终演示预算收束 | 只保留通过门禁的 AOT correlate/spectrogram 等路径 | 已关闭 |
| V7.6 | 以 V7-0011 字节回读完成最终关闭 | wall `101.971/240 s`，Top30 `30/30` | 最终版本 |

外部 SDK 中仍合法存在 `cuda*`、`cufft*`、`cublas*`、`cusolver*`、`.cu` 和
`dlcc -x cuda` 等兼容符号。V4 的命名迁移不能被误用为按字面删除这些平台接口。
