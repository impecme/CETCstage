# 中科芯平台迁移不兼容与修改台账

## 文档定位

本文档用于记录中科芯平台迁移过程中发现的关键不兼容点、关键修改点、暂缓点和 fallback。它是迁移过程的强制台账，不是日常操作流水账。

迁移期间不得只把关键问题记录在聊天记录、终端输出或个人笔记中。凡是影响构建、运行、数值、性能、报告、测试结论或协作方式的差异，都必须进入本文档。

## 记录规则

- 发现中科芯与 NVIDIA CUDA 的不兼容点时，新增记录。
- 发现会阻塞构建、运行、验证或协作的环境差异时，新增记录。
- 发现会影响数值、性能、报告字段、测试结论或 public API 的修改点时，新增记录。
- 普通操作过程、脚本改名、删减输出、命令整理、文档措辞调整等不单独入账，除非它们反映了平台硬约束或会影响迁移验收。
- 实施关键修改后，必须补充实际修改、影响范围和验证结果。
- 若问题暂缓，必须写明阻塞原因、fallback 范围和计划处理阶段。
- 若确认某问题不需要修改，必须写明原因和验证依据。
- 每个阶段结束前，必须检查本阶段发现项是否全部入账。

## 状态枚举

- `待确认`：现象已发现，尚未完成原因定位。
- `待修改`：已确认需要改动，但尚未实施。
- `修改中`：正在实施改动。
- `待验证`：改动已完成，等待 NVIDIA 或中科芯验证。
- `已关闭`：验证通过，记录完整。
- `暂缓`：暂时不处理，但必须有明确原因和后续阶段。
