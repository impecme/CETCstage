## 页面文字与视觉结构

标题：`核心亮点：全自动调优与三类算子机制`

副标题：`从路径选择、分层计算到 E2E 执行协议，形成可回退、可验证的 GPU 优化闭环。`

### 第一栏：全自动调优与形状感知分派

栏标题：`① 全自动调优与形状感知分派`

上部示意：完整调优键（算子、形状、dtype、layout、batch、语义参数）→ 有限候选路径 → 正确性门与 E2E 门 → 调优缓存 → 运行时查表选路；旁边画出缓存未命中、设备不匹配、资源不足或门禁失败时回退安全路径。用键、候选列表、门禁和缓存图形表达自动流程，不画人工逐项试配。

三行文字：

- `问题：固定路径难覆盖不同形状`
- `方法：自动候选搜索 / 完整键查表`
- `价值：自动选路，失败安全回退`

### 第二栏：分层 Tile、布局与归约

栏标题：`② 分层 Tile、布局与归约`

上部示意：重复全局读取的点×通道网格 → 点×相位输入 Tile、tap Tile 和共享 twiddle → 线程块协作加载、共享数据和分层归约 → 多通道并行输出。突出一次加载、多阶段块内使用和归约树，不画无意义装饰图。

三行文字：

- `问题：重复全局访存与串行归约`
- `方法：Tile 协作加载 / 分层归约`
- `价值：共享数据，多通道并行输出`

### 第三栏：非内核 E2E 开销与执行内资源复用

栏标题：`③ 非内核 E2E 开销与执行内资源复用`

上部示意：每个 warmup/repeat 独立创建输入、device buffer、plan、workspace、event 并完整 H2D；同一轮内部在 forward、频域中间阶段和 inverse 之间复用本轮 buffer/workspace；D2H 后释放本轮全部资源。明确标注“跨 repeat 不复用”。

三行文字：

- `问题：分配、计划、事件与物化拖慢 E2E`
- `方法：每轮独立 / 本轮内部复用`
- `价值：完整计入 H2D/D2H，减少非内核开销`

底部总结带：`自动选路、分层计算与 E2E 执行协议，共同形成可解释、可验证的 GPU 优化闭环。`
