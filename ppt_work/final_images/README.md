本目录只保存当前正式页序使用的整页 PNG，避免与 `../generated/` 中的历史迭代图混用。

当前已收录 P03～P08、P12～P19 共 14 张图片。P09～P11 为三层算子性能数据页，保留以下文件名但尚未生成，补入同协议真实数据后再汇编正式 PPT：

- `P10_赛题附录算子性能_待分层数据_v01.png`：`extended28`，扩展集合 28 算子；使用“赛题附录”标题前须与官方名单核对。

`task27` 是 `core53` 的优先子集，`extended28` 与 `core53` 共同构成 `all81`；三层性能页不可将 27、28、53 相加。

页序为：P03 赛题重述、P04 代码架构、P05 技术路线、P06～P08 三项公共技术、P09～P11 三层算子性能、P12～P13 Task1、P14～P15 Task2、P16 正确性、P17 优缺点与改进、P18 亮点、P19 AI 使用说明。

- `P06_访存资源复用_Wiener代表_v05_三项性能.png`：`filtering / wiener`。
- `P07_并行结构重构_IIR代表_v04_三项性能.png`：`filtering / lfilter`。
