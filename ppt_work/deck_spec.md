| 致谢 | P20 | 0:10 | 结束 |

## 2. 叙事主线

```text
赛题交付与代码架构
  → 三项公共机制：复用、归约、特化
  → 三层算子性能：27 / 26 / 28
  → 任务一：公开算子链与端到端性能
  → 任务二：批量评分链与端到端性能
  → 验证、热点、改进方向
  → 三类结构重构亮点
```

所有性能页统一使用：

- **最终 GPU 耗时**：GPU 端到端中位时间。
- **CPU/GPU 加速比**：CPU 中位时间 ÷ 最终 GPU 中位时间。
- **GPU 优化前后提速**：当前统一显示 `X×`，待同规模 Git 基线复测后替换；不得用 CPU/GPU 加速比代替。
